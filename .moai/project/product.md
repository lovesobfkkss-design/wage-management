# 강한영어수학학원 급여관리시스템

## 제품 개요

학원 운영에 특화된 웹 기반 급여 관리 시스템입니다. 시급제 직원(조교·파트강사), 4대보험 직원, 월급제 3.3% 강사, 비율제 강사, 특강까지 다섯 가지 급여 유형을 한 곳에서 정산합니다. 학원(학원코드)별로 데이터가 분리되며, Firebase 실시간 동기화로 여러 기기에서 동시에 사용할 수 있습니다.

## 타겟 사용자

- **관리자**: 학원 원장 또는 급여 담당자 (학원코드 + 로그인 ID + 비밀번호)
- **직원**: 조교, 파트강사 (가입 신청 후 관리자 승인을 받아 로그인)

## 급여 유형

| 유형 | 대상 | 계산 방식 | 공제 |
|------|------|-----------|------|
| 시급제 | 조교, 파트강사 | 근무기록 시간 × 시급 (2구간 시급, 반올림 규칙) | 조교 고용보험 0.9% / 파트강사 3.3% |
| 4대보험 | 월급제 정직원 | 월 급여 − 결근 공제 | 4대보험 + 소득세 + 지방소득세 |
| 월급제 3.3% | 월급제 강사 | 기본 월급 자동 적용 또는 월별 입력 | 사업소득세 3.3% + 추가 공제 |
| 비율제 | 비율제 강사 | 학생 수강료 합계 × 수수료 비율 | 카드수수료 1% + 3.3% |
| 특강 | 특강 담당 강사 | 특강별 수강료 × 비율 (강사별 합산) | 카드수수료 1% + 3.3% (특강별 제외 가능) |

## 핵심 기능

### 1. 학원별 계정과 사업장
- 학원 관리자 가입, 학원코드 기반 로그인, 휴대폰 번호로 비밀번호 찾기
- 한 학원 안에서 여러 사업장(지점)을 관리하고 사업장별로 필터링

### 2. 직원 가입과 본인 정보
- 직원이 직접 가입 신청 (이름, 휴대폰, 주민등록번호, 급여 계좌)
- 관리자가 설정 탭에서 승인하며 소속·시급 조건을 지정
- 직원은 로그인 후 "내 정보"에서 급여 계좌와 비밀번호를 직접 수정

### 3. 직원관리 (시급제)
- 재직 / 퇴사 / 전체 보기 전환, 퇴사자는 퇴사일 순 정렬과 월별 구분
- 급여 계좌 표시와 복사, 주민등록번호, 입사일·퇴사일, 직급 관리

### 4. 4대보험 직원
- 세무사 급여명세서와 같은 방식으로 공제 계산
  - 비과세(식대 등)를 뺀 과세급여 기준으로 고용보험·소득세 계산
  - 국민연금 기준소득월액, 건강보험 보수월액을 직원별로 입력 (공단 신고 금액)
  - 각 항목 10원 미만 절사, 소득세는 간이세액표 산출 공식으로 계산
- 요율은 설정 탭에서 조정, 결근일수 입력 시 일할 공제

### 5. 월급제 3.3% 강사
- 기본 월급을 넣어두면 매달 자동 적용, 금액이 다른 달만 월별 입력
- 월급이 입력되지 않아 합계에서 빠진 강사를 경고로 표시
- 전원의 월급을 한 화면에서 입력하는 "한번에 입력"

### 6. 비율제 강사 · 특강
- 월별 학생 명단과 수강료 관리, Excel/CSV 일괄 등록
- 특강은 강사별로 묶어 한 줄로 정산

### 7. 근무 기록
- 직원 본인의 출퇴근 기록, 수동 입력, 휴게시간
- 관리자의 근무기록 수정과 수정 이력 보관

### 8. 급여 정산
- 다섯 유형을 하나의 표로 통합, 유형 필터와 정렬
- 급여명세서 PDF 출력, Excel 다운로드

### 9. 대시보드
- 월 지급 예정액, 유형별 소계, 급여 현황
- 월별 비교 (최근 3·6·12개월): 유형별 총액 추이, 사람별 월별 실지급액
- 변동 분석: 전월 대비 증감, 이전 달 평균 대비, 신규·빠짐 인원, 직원별 증감과 추이

### 10. 문자 생성과 발송
- 급여 안내 문자 자동 생성, 복사
- 알리고(Aligo) 연동 SMS 발송 (테스트 발송 지원, 발송 이력 저장)

## 사용 사례

1. **월말 급여 정산**: 근무기록 확인 → 월급제 강사 월급 확인 → 급여정산 탭에서 검토 → PDF/Excel 출력 → 문자 발송
2. **세무사 명세서 대조**: 4대보험 직원의 비과세·기준 금액 입력 → 공제액이 명세서와 일치하는지 확인
3. **신규 직원 등록**: 직원이 가입 신청하며 계좌 입력 → 관리자가 승인
4. **지출 점검**: 대시보드 변동 분석에서 전월 대비 증감과 원인(유형·사람) 확인

## 기술적 특징

- 별도 서버 설치 불필요 (Firebase + Vercel)
- 모바일 반응형 디자인
- 빌드 과정 없이 브라우저에서 바로 실행
